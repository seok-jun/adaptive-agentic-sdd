# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive in issues, discussions and pull requests. Critique rules, evidence and code, not people. Harassment, personal attacks and publishing others' private information are not acceptable.

To report a concern, contact the maintainer, [@seok-jun](https://github.com/seok-jun), through GitHub. Reports are handled privately. The maintainer may edit or remove content and restrict participation in this repository when the Covenant is not followed.
