# v1.0.2 — 2026-11-07

Stable release: [v1.0.2](https://github.com/seok-jun/adaptive-agentic-sdd/releases/tag/v1.0.2). Includes [PR #11](https://github.com/seok-jun/adaptive-agentic-sdd/pull/11), [#12](https://github.com/seok-jun/adaptive-agentic-sdd/pull/12), [#13](https://github.com/seok-jun/adaptive-agentic-sdd/pull/13) and [#14](https://github.com/seok-jun/adaptive-agentic-sdd/pull/14), plus publication metadata. The immutable tag identifies the final release commit; v1.0.1 remains unchanged.

## Changes

- One-command try sandbox: `try/setup.py` (Python 3.8+ standard library, Git 2.36+) creates a disposable, offline folder with a small two-module product, a project-owned W with all nine project documents filled for it, local bare remotes, local-docs records and the user allowlist, then confirms product tests and resolver READY. It refuses an existing target or one inside the checkout, writes only inside the target and never deletes anything. `START-HERE.md` gives Claude Code and Codex launch commands, the selection prompt and three planted tasks (Trivial, Small, Large), in English or Korean.
- README (English and Korean) leads with a one-line summary, a risk-grading diagram, a three-step quick start that starts with the try sandbox, and an animated demo shortened from two real Codex runs. Detailed adoption steps moved lower; earlier evidence is folded, not removed.
- The current behavior and paired-skill eval runners keep Claude Code session records (no `--no-session-persistence`), so headless runs can be counted by local usage accounting. Isolation flags are unchanged; the historical v1 runner keeps its recorded invocation.
- Issue forms for try / first-use feedback and bugs, questions routed to Discussions, and a code of conduct (Contributor Covenant 2.1 by reference).

**Distribution unchanged:** no file under `methodology/`, `adaptive-sdd/` or `ko/adaptive-sdd/` changed since v1.0.1, so all manifests are unchanged. Existing project-owned W needs no update for this release.

## Verification and limits

- Windows: all 123 executable tests passed on the release tree (117 existing plus the try-sandbox and runner regression tests). All five manifests match their files; repository-wide local Markdown links and anchors passed; `git diff --check` passed.
- macOS 12.7.6 (Python 3.14, Git 2.37, x86_64), at `bb81b27` of PR #12: both editions of `try/setup.py` reached READY, the existing-target refusal left the target unchanged, START-HERE showed POSIX commands, and all 123 tests passed. Linux was not run.
- [Try-sandbox runs](../eval-results/2026-11-07-try-sandbox/README.md): Codex on Windows completed the Small task end to end and stopped the Large task for human decisions without changing product code; Claude Code on macOS completed the Small task (agent's own report). One run per task, English edition only. The Large stop follows a rule the sample product states explicitly. Host sandbox enforcement was not tested.
- No behavior/effect experiment was run for this release; effect on outcomes, rework or cost remains unmeasured.
