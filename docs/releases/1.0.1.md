# v1.0.1 — 2026-11-07

Stable release: [v1.0.1](https://github.com/seok-jun/adaptive-agentic-sdd/releases/tag/v1.0.1). Includes [PR #10](https://github.com/seok-jun/adaptive-agentic-sdd/pull/10), merged at `5de2866fbb4e1c78cf24e4ec4df925660576e360`, plus publication metadata. The immutable tag identifies the final release commit; v1.0.0 remains unchanged.

## Changes

- English and Korean compact routes for routine Trivial/Small work. Reuse unchanged inputs, place start facts in CLAIM and avoid repeating the full SUMMARY at closure. Required verification, escalation, merge authority and claim ownership remain.
- Helper scripts, message files, caches and build outputs are scoped writes. Prefer existing tools/stdin/memory; use authorized task-specific scratch when files are needed.
- Adoption guidance covers actual host sandbox probes, bounded Git trust for sandbox accounts and accessible toolchains. Optional model/cost metadata does not require searching host transcript/config directories during routine tasks.
- Three additional synthetic policy cases per edition; 89 cases per edition and 70 files in each distribution manifest. These cases are specifications, not behavior scores.

## Verification and limits

The final release tree passed all 117 executable tests on Windows. Both 70-file bundle manifests match exact serialization and file hashes; unchanged M manifests remain valid. Changed-document local link targets and Git whitespace/conflict checks passed.

[Five-language trial report](../eval-results/2026-11-06-small-route/README.md): Python, JavaScript, TypeScript, Java and Go tasks used requested Codex `gpt-6.1-sol` / high. First attempts completed 3/5; after two preserved environment-blocked attempts were corrected, all five completed and passed independent behavior, allowed-file, W-integrity, merge-identity and closure checks. Completed runs showed no observed out-of-area agent writes and one SUMMARY each. A separate sandbox preflight accepted an inside write and denied an outside write.

This is not a controlled speed or efficacy experiment. Completed attempts still took about 4.5–5.7 minutes; model, task and environment differed from the earlier trial. The methodology does not install an OS sandbox, and resolver READY does not enforce write boundaries. No new Medium/Large, competing-claim, native macOS/Linux, Korean-subject or live GitHub tracker lifecycle was tested in this patch. See the trial report and [1.0.0 release record](1.0.0.md) for earlier evidence and its scope.

## Adoption

Start with the [English guide](../customization.md) or [Korean guide](../../ko/docs/customization.md). Existing project-owned W is not overwritten or automatically upgraded: review these changes under project authority, commit the adopted W and select its new commit for later tasks. Active tasks keep their selected snapshot. Legacy installations follow their separate [upgrade procedure](../legacy-installation.md#upgrading).
