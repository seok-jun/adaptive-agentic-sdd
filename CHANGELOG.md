# Changelog

## 0.2.0

Portable agent-runtime update based on repeated repository operation.

Adds:

- Trivial fast-track grade,
- progressive-disclosure instruction architecture (`AGENTS.md` -> Skill -> conditional docs),
- portable-core vs project-local policy separation,
- bootstrap guidance for existing repositories,
- phase-aware review packets,
- review finding classification,
- revision-bound Human approval semantics,
- starter `AGENTS.md` and implementation Skill examples,
- updated token/context efficiency guidance.

The v0.2 portable core intentionally does **not** make project-specific model routing, build-tool workarounds, or universal blind-audit requirements part of the base methodology.

## 0.1.0

Initial public working methodology.

Includes:

- Issue-first execution,
- information-specific Source of Truth,
- risk grades,
- bounded AS-IS analysis,
- Verification Strategy,
- Trade-off Capture,
- grade-based review,
- conditional Device QA,
- token/context efficiency principles,
- lifecycle cleanup.
