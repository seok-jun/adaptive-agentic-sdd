# SDD 단계별 규칙 경로

W는 공통 분류와 수행법, M은 공통 원칙을 소유한다. P의 적용 선언·제품 사실·사람 권한·필수 검증은 `S/.adaptive-sdd/project/sdd-workflow.md`가 원본이다. 아래 파일은 현재 행동에 해당할 때 직접 읽는다. Skill에서 경로를 받았다면 이 안내를 거칠 필요가 없다. 같은 run에서 확인한 동일 버전은 재사용하며 참조된 모든 문서를 선행 로딩하지 않는다.
